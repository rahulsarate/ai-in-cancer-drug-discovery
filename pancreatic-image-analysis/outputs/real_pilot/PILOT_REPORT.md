- Descriptive model-MAE 95% interval: [0.9368743849791856, 1.495945879220544].
- Baseline-minus-model MAE improvement: 0.1756; descriptive interval: [-0.13473089520778447, 0.4756352645367818].
- RMSE: 1.4087; R-squared: 0.1262; Spearman r: 0.0826.
- The image model had lower point-estimate error than the training-mean baseline.
- The descriptive improvement interval includes zero; predictive advantage is not established.
- Leave-one-source-site-out evaluation within TCGA only. Bootstrap intervals are conditional on fixed predictions and omit site clustering and model refitting.
- The target is a prespecified, unbounded bulk RNA expression contrast, not a validated EMT assay. Stromal confounding and block mismatch remain.
