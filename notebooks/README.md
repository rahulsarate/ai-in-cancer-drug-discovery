# Notebooks

Suggested notebooks:

1. `01_tcga_emt_scoring.ipynb`: load TCGA expression, score EMT/TME programs, run survival association.
2. `02_single_cell_benchmark.ipynb`: compare atlas scores against CancerSEA/TISCH2 malignant-cell states.
3. `03_stromal_correction.ipynb`: separate tumor-cell EMT from fibroblast/CAF contamination.
4. `04_target_ranker_inputs.ipynb`: build target evidence tables from DepMap, PRISM, LINCS, Open Targets, ChEMBL, and DGIdb.
5. `05_target_prioritization_report.ipynb`: create ranked target reports and visual summaries.
